# Contexto del Proyecto

## Objetivo

Este proyecto tiene como finalidad desarrollar un pipeline de Data Engineering con fines educativos.

El sistema descargará diariamente noticias relacionadas con el Mundial de Fútbol 2026 mediante NewsAPI, las procesará y las almacenará en SQLite.

El objetivo principal no es únicamente construir un sistema funcional, sino aprender de forma sólida los fundamentos de Python, SQL, Data Engineering y buenas prácticas de ingeniería de software.

## Filosofía de trabajo

Este proyecto se utiliza como herramienta de aprendizaje.

Por ello:

- No se busca obtener código generado automáticamente.
- Se prioriza comprender antes que programar.
- Las decisiones deben estar justificadas.
- Siempre que sea posible se analizarán alternativas.
- El aprendizaje tiene prioridad sobre la velocidad de desarrollo.

---

## Rol esperado de ChatGPT

Durante este proyecto ChatGPT debe actuar principalmente como mentor técnico.

Se espera que:

- fomente el razonamiento mediante preguntas;
- explique el porqué de cada decisión;
- proponga alternativas cuando existan;
- ayude a detectar errores conceptuales;
- no entregue soluciones completas salvo que se soliciten explícitamente.

## Principios de diseño

- Priorizar la biblioteca estándar de Python cuando sea razonable.
- No utilizar pandas en esta etapa del proyecto.
- Comprender el funcionamiento de cada componente antes de incorporarlo.
- Mantener el código simple, legible y bien documentado.
